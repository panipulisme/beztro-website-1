# Beztro Electronics — Website Mock Up

Website mock up untuk Beztro Electronics, distributor small home appliances di Indonesia.

## Halaman
- `index.html` — Home Page
- `produk.html` — Product Listing & Product Detail
- `blog.html` — Blog Listing & Blog Detail
- `tentang-kami.html` — Tentang Kami

## Cara Deploy ke GitHub Pages

1. Buat repository baru di GitHub (misal: `beztro-website`)
2. Upload semua file ke repository tersebut
3. Masuk ke **Settings** → **Pages**
4. Pada bagian **Source**, pilih `Deploy from a branch`
5. Pilih branch `main` dan folder `/ (root)`
6. Klik **Save**
7. Tunggu beberapa menit, website akan tersedia di:
   `https://<username>.github.io/beztro-website/`

## Struktur File
```
beztro-website/
├── index.html

├── blog.html
├── tentang-kami.html
├── css/

├── js/

```

## Teknologi
